# TradingSimulator

证券交易模拟器。当前已实现 M0–M4：确定性撮合内核、零智力噪声市场、Q-learning 智能投资者、异质策略 Agent 与宏观情景引擎、玩家交易闭环、A 股涨跌停，以及 WebSocket 网关与浏览器交易终端。

## 已实现

- M0：价格—时间优先的限价订单簿，支持部分成交和撤单
- M0：买单资金冻结、卖单可卖数量冻结，以及 T+1 买入持仓结算
- M0：定点整数价格/数量/金额，稳定事件排序和确定性事件回放
- M1：无依赖的确定性随机数（xoshiro256++）、成交带 OHLCV K线聚合、统计估计器
- M1：零智力噪声 Agent 市场（泊松唤醒、触价锚定报价、对数正态重尾订单），参数已按程式化事实验收校准（无自相关、近随机游走扩散、肥尾量能）
- M2：Q-learning 智能投资者（盘口观察、五动作决策、价差捕获奖励 + 库存风险惩罚、确定性人格异质性），与噪声群体混合交易，固定种子下逐位可复现
- M2：共享离散事件仿真核心（事件堆、回放日志、成交磁带、订单生命周期跟踪），M1/M2/M3/M4 层统一构建其上
- M3：异质策略 Agent 群体——做市商（双边报价 + 库存倾斜）、趋势跟随者（快慢均线交叉）、均值回归者（锚定价格带）、基本面投资者（私有估值 + 制度漂移）
- M3：Markov 宏观情景引擎（平静/牛市/熊市/危机四态切换，调制各策略群体活跃度、报价宽度与漂移），叠加日内 U 型成交量节律
- M3：程式化事实验收——波动率聚集（|r| 自相关衰减）、量-波动正相关、日终清账与簿完整性不变量，全部通过且固定种子可复现
- M4：A 股涨跌停价格笼子（±bp 日内限价带、贴边合法、超限拒单、随 T+1 日结按收盘价滚动）
- M4：玩家交易闭环——与 Agent 共用同一订单簿/磁带/回放日志，限价提交（手数整倍）、撤单、虚拟时钟推进（advance_ms）、全量快照（盘口十档/持仓/资金/权益盯市）
- M4：庄家 Agent（拉高出货状态机：被动吸筹 → 扫单拉升 → 跨结算日出货），操纵弧线可观察、可验收
- M4：验收测试——价格笼子门控、玩家 T+1 回路与现金流精确守恒、操纵轨迹（拉升 ≥2% 后回落）、玩家事件纳入确定性回放
- M4 网关：tokio + axum 异步 WebSocket——每连接独占一个会话（自有种子与虚拟时钟），10Hz tick 广播全量快照，IO 与仿真热路径隔离，慢客户端只拖慢自己
- M4 网关：JSON 协议（order/cancel/speed）带序号回执，成交与挂单状态可区分；同一二进制经 ServeDir 托管前端产物
- M4 前端：React + Canvas 交易终端——K 线/成交量图（含涨跌停带阴影）、十档热度盘口、委托下单（买卖一快捷填价）、逐笔成交、账户与挂单（T+1 区分）、回执通知
- M4 前端：速度控制（暂停/1×/5×/20× 虚拟时钟快进）、宏观制度徽章、庄家阶段叙事提示（吸筹/拉升警示/出货/回归平静）

## 运行

```powershell
# 1) 构建前端产物（首次或前端变更后）
cd frontend && pnpm install && pnpm build && cd ..

# 2) 构建并启动网关（默认 8080 端口，托管 frontend/dist）
cargo run -p gateway
```

浏览器打开 http://127.0.0.1:8080 即进入交易终端。

前端开发模式（5173 端口，`/ws` 代理到网关）：`cd frontend && pnpm dev`。
